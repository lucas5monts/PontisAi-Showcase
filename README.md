# Pontis

**Daily sports and market predictions, written for casual bettors.**

🔗 **Live board:** [pontisai.pages.dev](https://pontisai.pages.dev)

Pontis turns data into a simple daily board: who's likely to win, how confident the model is, and what that's worth in dollars — no stats jargon.

## What it covers
- **Sports:** MLB, NFL, NBA, WNBA, college football, golf, UFC, soccer
- **Markets:** stocks and crypto

## How it works
- Automated pipelines pull fresh data and rebuild predictions every day
- Models are retrained and checked against past seasons before anything goes on the board
- The board updates itself — no manual steps
- An iOS app is in development

## Built with
Python · pandas · scikit-learn · Cloudflare Pages · SwiftUI

## Status
Pontis is pre-launch. The source code is private for now; this repo is the public home for the project.

## Disclaimer
Pontis is for entertainment and research. Nothing here is betting or financial advice.
